# Верхнеуровневое описание процесса добавления устройств и датчиков

1. Пользователь добавляет новый дом согласно [(1)](#1)
2. Пользователь добавляет новое устройство для умного дома согласно [(2)](#2)
3. Пользователь добавляет новый датчик для умного дома согласно [(3)](#3)

---

## <a id="1"></a>(1)

### Описание
Пользователь подключает новый дом

### Предварительные условия
Пользователь заведён в систему через портал сотрудника (не рассматривается в данной задаче)

### Результат
Пользователь имеет возможность добавлять новые устройства и управлять умным домом

### Последовательность шагов

1. Пользователь через интерфейс управления добавляет новый дом вызывая сервис управления домом через api gateway `REST/POST /home`
    - а. Если возникла ошибка добавления, пользователь должен увидеть соответствующее окно с ошибкой. При нажатии на кнопку "повтор" выполняется повторная интеграция
    - б. Иначе в сервисе "Управление домом" появляется новая запись с соответствующими данными

## <a id="2"></a>(2)

### Описание
Пользователь подключает новое устройство умного дома

### Предварительные условия
Создан хотя бы 1 "дом" пользователя

### Результат
Пользователь имеет возможность просматривать работу умного устройства и управлять им

### Последовательность шагов

1. Пользователь через интерфейс управления добавляет новое устройство вызывая сервис управления устройствами через api gateway `REST/POST /device`
    - а. Если возникла ошибка добавления, пользователь должен увидеть соответствующее окно с ошибкой. При нажатии на кнопку "повтор" выполняется повторная интеграция
    - б. Иначе в сервисе "Управление устройством" появляется новая запись с соответствующими данными

---

## <a id="3"></a>(3)

### Описание
Пользователь подключает новый датчик умного дома

### Предварительные условия
- Создано сопутствующее устройство умного дома
- У пользователя есть возможность добавить датчик к существующему устройству умного дома

### Результат
Подключён датчик для real time телеметрии

### Последовательность шагов

1. Пользователь через интерфейс управления добавляет новый датчик вызывая сервис управления датчиками через api gateway `REST/POST /sensor`
    - а. Если возникла ошибка добавления, пользователь должен увидеть соответствующее окно с ошибкой. При нажатии на кнопку "повтор" выполняется повторная интеграция
    - б. Иначе в сервисе "Датчик" появляется новая запись с соответствующими данными
