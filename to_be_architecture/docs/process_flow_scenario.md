# Верхнеуровневое описание процесса работы со сценариями

1. Пользователь создаёт новый сценарий [(1)](#1)
2. Пользователь запускает новый сценарий [(2)](#2)

---

## <a id="1"></a>(1)

### Описание
Пользователь создаёт новый сценарий

### Предварительные условия
-

### Результат
Создан новый пользовательский сценарий для дома

### Последовательность шагов

1. Пользователь через интерфейс пользователя выбирает нужный дом
    - а. Выполняется интеграция `REST/GET /home`
    - б. Пользователь выбирает нужный дом `REST/GET /home{id}`
2. Пользователь создаёт новый сценарий `REST/POST /scenario`
    - а. Возвращается в кэш интерфейса id сценария (scenarioId)
3. Выполняется интеграция `REST/GET /device{homeId}`
4. Пользователь выбирает нужное устройство из списка
5. Пользователь создаёт новую запись последовательности действий для устройства `REST/POST /scenario{scenarioId}`

## <a id="2"></a>(2)

### Описание
Пользователь запускает новый сценарий

### Предварительные условия
Сценарий был создан

### Результат
Запустился сценарий

### Последовательность шагов

1. Пользователь запускает сценарий `REST/GET /scenario{id}`
2. Сервис сценария обрабатывает запрос
    - а. Если в сценарии нет связанных устройств сценария, то выход
    - б. Иначе п.3
3. Сервис сценария отправляет эвент `ChangeStateFromScenario`
4. Сервис управления устройствами считывает эвент `ChangeStateFromScenario`
    - а. Если у устройства выставлено `isAvailable = false`, то выход
    - б. Иначе обрабатывает логику изменения состояния устройства
5. Сервис управления устройствами отправляет эвент `ChangeDeviceStateFromScenario`
6. API Gateway считывает событие и отправляет запрос на устройство умного дома через hub `REST/PUT`
    - а. Если возникла ошибка интеграции, то выполняется повтор (количество повторов - 3). При достижении 3 повторов - п.7
    - б. Иначе выход
7. Gateway вызывает сервис управления устройствами `REST/PUT /device{id}`, передав ошибку
8. Сервис управления устройствами выставляет флаг "устройство недоступно" (пользователь, обновив интерфейс, видит проблему с устройством и может его переподключить)
