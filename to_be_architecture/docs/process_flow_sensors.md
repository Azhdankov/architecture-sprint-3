# Верхнеуровневое описание процесса работы с датчиками

1. Датчик выполняет REST запрос на сервис управления датчиками при изменении состояния [(1)](#1)
2. Сервис "Управление устройством" осуществляет интеграцию с IoT устройством пользователя если необходимо [(2)](#2)

---

## <a id="1"></a>(1)

### Описание
Отправка информации об изменении состояния датчиком

### Предварительные условия
-

### Результат
Отправлено событие на изменение состояния устройства умного дома

### Последовательность шагов

1. Датчик выполняет интеграцию с актуальным состоянием в момент его изменения к сервису управления датчиками через api gateway `REST/PUT /sensor{id}`
2. Сервис управления датчиками обрабатывает запрос и создаёт событие `ChangingState`
3. Сервис телеметрии считывает `ChangingState` и сохраняет новое состояние в Redis
4. Сервис управления устройствами считывает событие `ChangingState`
    - а. Если переданное состояние требует изменения состояния устройства, то [(2)](#2)
    - б. Иначе выход

## <a id="2"></a>(2)

### Описание
Отправка информации по изменению работы умного устройства

### Предварительные условия
Получен запрос на изменение состояния от датчика

### Результат
Устройство умного дома скорректировало свою работу

### Последовательность шагов

1. Сервис управления устройствами отправляет событие `ChangingDeviceState`
2. API Gateway считывает событие и отправляет запрос на устройство умного дома через Hub `REST/PUT`
    - а. Если возникла ошибка интеграции, то выполняется повтор (количество повторов - 3). При достижении 3 повторов - п.3
    - б. Иначе выход
3. Gateway вызывает сервис управления устройствами `REST/PUT /device{id}`, передав ошибку
4. Сервис управления устройствами выставляет флаг "устройство недоступно" (пользователь, обновив интерфейс, видит проблему с устройством и может его переподключить)
